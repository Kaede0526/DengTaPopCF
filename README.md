# 穿越火线 · 主奖池 道具抽奖模拟器

一个可**完全离线**运行的 CF「主奖池」道具抽奖 + 欢乐值兑换模拟器，单页面 + 静态资源 供诸位参考
- 抽奖：按公示概率加权随机（区间累加），支持抽 1 次 / 十连
- 兑换：欢乐值钱包，主奖池产出欢乐值，可在兑换区消耗换道具
- 商城：按活动原价购买复活币赠送抽奖钥匙
- 验证：内置 Monte-Carlo 大样本分布测试，核对实测占比与公示概率
- 视觉：整页背景（Ken-Burns 动效 + 金色粒子），可开关

## 文件结构

```
cf-deploy/
├── index.html           # 页面主入口（自包含逻辑，无第三方依赖）
└── assets/
    ├── bg.jpg           # 整页背景图
    └── popget1..16.png  # 16 张道具图（序号对应主奖池 1~16 项）
```

> 数据来源：下载框架 `抽奖_files/index.html` 的主奖池「概率公示」表。
> 页面为纯本地单文件逻辑，除 assets 图片外**无任何网络请求**。

## 本地运行

直接双击 `index.html` 在浏览器打开即可（图片走相对路径，`index.html` 与 `assets/` 需保持同目录）。

## 自定义修改

打开 `index.html`，编辑文件末尾 `<script>` 里的数据常量：

| 想改什么 | 常量 / 位置 |
|---|---|
| 奖项与概率 | `PRIZES`（name / prob / tier / joy） |
| 稀有度分级 | `TIER`、`RARE_ORDER` |
| 钥匙购买价格档 | `PACKS`（qb=Q币, fhb=复活币, key=钥匙） |
| 兑换区示例项 | `defaultOffers()` |
| 初始余额 | `state` 里的 qb / keys / joy |
| 背景图 / 道具图 | `assets/` 同名替换即可 |

兑换区也能在页面右下「＋ 管理兑换项」中直接增删改，无需改代码。
